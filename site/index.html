rag-docs-chatbot · open source

Answers that show their page.

A retrieval-augmented chatbot over two NIST digital identity standards. Every claim links to the passage it came from, and it says so when the documents don't cover a question.

Try the live demo Watch the walkthrough Source on GitHub

The live demo runs on a free open model (ling-3.2-flash via OpenRouter), so answers can take a few seconds. 8 questions per visitor per rolling hour.

Sample answer

Do verifiers require subscribers to change passwords periodically?

No. Verifiers and CSPs SHALL NOT require subscribers to change passwords periodically [1].

SP 800-63B-4 p. 25

Verifiers and CSPs SHALL NOT require subscribers to change passwords periodically. However, verifiers SHALL force a change if there is evidence of compromise of the authenticator.

PIPELINE

How an answer is built

  1. 01

    Ingest

    PDFs, Markdown and HTML into 400-token chunks.

  2. 02

    Embed

    Locally with BGE.

  3. 03

    Search

    Postgres with pgvector and full-text, fused by reciprocal rank fusion.

  4. 04

    Rerank

    Optionally with a MiniLM cross-encoder.

  5. 05

    Answer

    With a free open model, falling back across providers.

  6. 06

    Cite

    Every claim, or say “I don't know”.

QUICKSTART

Run it yourself

Clone the repository, start Postgres with pgvector, ingest the two NIST documents, and serve the app locally. Ingestion and retrieval work without a model key; answering needs an Ollama Cloud, OpenRouter or Anthropic key.

git clone https://github.com/willowvibe/rag-docs-chatbot && cd rag-docs-chatbot
make up
make ingest
make serve
